## ☁️ 配置云开发环境

### 什么是云开发？

微信云开发（CloudBase）是一个低成本的服务器方案，无需购买云服务器，即可使用云数据库、云存储、云函数等功能。

**优点**：
- ✅ 免费额度充足（每天50万次调用）
- ✅ 无需服务器运维
- ✅ 数据安全，微信生态内访问
- ✅ 自动扩缩容

### 步骤1：开通云开发

1. 在微信开发者工具中，点击右上角的"云开发"按钮
2. 同意服务协议
3. 创建一个新的云环境
4. 等待环境创建完成（通常需要1-2分钟）
5. 记录云环境ID（例如：`drone-info-xxxx`）

### 步骤2：配置云环境ID

修改以下文件中的云环境ID：

**文件1: `miniprogram/app.js`**
```javascript
wx.cloud.init({
  env: 'drone-info-xxxx', // 替换为您的云环境ID
  traceUser: true,
})
```

**文件2: `miniprogram/utils/api.js`**
```javascript
const CLOUD_ENV = 'drone-info-xxxx' // 替换为您的云环境ID
```

### 步骤3：创建数据库集合

1. 打开微信开发者工具
2. 点击"云开发"按钮
3. 进入"数据库"标签
4. 点击"+"创建集合
5. 集合名称：`articles`
6. 重复创建：`statistics`

## 🔄 数据同步方案

由于微信小程序使用的是云开发数据库，而您的数据采集系统使用的是本地SQLite数据库，需要进行数据同步。

### 方案A：手动同步（简单，适合初期）

1. 在本地运行数据采集
2. 运行数据导出脚本
3. 在小程序后台手动导入

**实现步骤**：

#### 步骤1：创建数据导出脚本

在您的项目中创建 `export_for_miniprogram.py`：

```python
"""
导出数据到JSON格式，供微信小程序云开发使用
"""
import sqlite3
import json
from datetime import datetime, timedelta

def export_articles_to_json(db_path="data/drone_scout.db", output_file="wechat_mini_program/articles.json"):
    """导出文章数据到JSON文件"""
    
    conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row
    cursor = conn.cursor()
    
    # 获取最近90天的文章
    start_date = (datetime.now() - timedelta(days=90)).strftime('%Y-%m-%d')
    
    cursor.execute("""
        SELECT 
            id,
            title,
            content,
            url,
            source,
            publish_date,
            region,
            drone_type,
            company,
            keywords,
            summary
        FROM articles 
        WHERE publish_date >= ?
        ORDER BY publish_date DESC, created_at DESC
    """, (start_date,))
    
    articles = []
    for row in cursor.fetchall():
        article = dict(row)
        # 转换日期格式
        if article.get('publish_date'):
            article['publish_date'] = str(article['publish_date'])
        articles.append(article)
    
    conn.close()
    
    # 导出到JSON
    with open(output_file, 'w', encoding='utf-8') as f:
        json.dump(articles, f, ensure_ascii=False, indent=2)
    
    print(f"✅ 成功导出 {len(articles)} 篇文章")
    print(f"📁 文件位置: {output_file}")
    return len(articles)

if __name__ == "__main__":
    count = export_articles_to_json()
    if count > 0:
        print("\n📋 下一步操作：")
        print("1. 在微信开发者工具中打开云开发")
        print("2. 进入数据库")
        print("3. 点击 articles 集合")
        print("4. 点击'导入'按钮")
        print("5. 选择 articles.json 文件")
        print("6. 配置字段类型映射")
        print("7. 完成导入")
```

#### 步骤2：运行导出脚本


### 方案B：自动同步（推荐，适合长期使用）

#### 创建云函数自动同步

**步骤1：创建云函数**

1. 在微信开发者工具中，右键点击 `cloudfunctions` 文件夹
2. 选择"新建Node.js云函数"
3. 命名为 `syncData`

**步骤2：编写云函数代码**

创建 `cloudfunctions/syncData/index.js`：

```javascript
const cloud = require('wx-server-sdk')

cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })

const db = cloud.database()

exports.main = async (event, context) => {
  try {
    const { articles } = event
    
    // 批量插入或更新
    const tasks = articles.map(article => {
      return db.collection('articles').add({
        data: {
          ...article,
          _openid: undefined, // 移除openid字段
          created_at: new Date()
        }
      })
    })
    
    await Promise.all(tasks)
    
    return {
      success: true,
      count: articles.length
    }
  } catch (error) {
    return {
      success: false,
      error: error.message
    }
  }
}
```

**步骤3：部署云函数**

1. 右键点击 `syncData` 文件夹
2. 选择"上传并部署"
3. 等待部署完成

#### 创建本地同步脚本

在您的项目中创建 `sync_to_miniprogram.py`：

```python
"""
自动同步数据到微信小程序云数据库
"""
import requests

import sqlite3
from datetime import datetime, timedelta

def sync_to_wechat_cloud():
    """同步数据到微信云开发"""
    
    # 获取文章数据
    conn = sqlite3.connect("data/drone_scout.db")
    cursor = conn.cursor()
    
    start_date = (datetime.now() - timedelta(days=90)).strftime('%Y-%m-%d')
    
    cursor.execute("""
        SELECT id, title, content, url, source, publish_date, 
               region, drone_type, company, keywords, summary
        FROM articles 
        WHERE publish_date >= ?
        ORDER BY publish_date DESC
    """, (start_date,))
    
    articles = []
    for row in cursor.fetchall():
        article = {
            'id': row[0],
            'title': row[1],
            'content': row[2],
            'url': row[3],
            'source': row[4],
            'publish_date': str(row[5]),
            'region': row[6],
            'drone_type': row[7],
            'company': row[8],
            'keywords': row[9],
            'summary': row[10]
        }
        articles.append(article)
    
    conn.close()
    
    print(f"获取到 {len(articles)} 篇文章")
```

## 🧪 测试与调试

### 本地测试

1. **启动开发者工具**
   - 打开微信开发者工具
   - 导入项目
   - 确保勾选"调试"模式

2. **检查云开发连接**
   - 点击"云开发"按钮
   - 确认云环境已开通
   - 检查数据库是否有数据

3. **测试页面功能**
   - 首页加载是否正常
   - 统计数据是否显示
   - 文章列表是否正常
   - 文章详情是否正常
   - 搜索功能是否正常

### 常见问题排查

#### 问题1：云开发连接失败

**原因**：云环境未正确配置

**解决方案**：
1. 检查 `app.js` 中的环境ID是否正确
2. 确认云环境已开通
3. 重新编译项目

#### 问题2：数据库查询失败

**原因**：集合名称不匹配或权限配置错误

**解决方案**：
1. 检查集合名称是否一致
2. 检查数据库权限设置
3. 查看控制台错误信息

#### 问题3：图片无法显示

**原因**：云存储权限或路径问题

**解决方案**：
1. 检查图片URL是否正确
2. 确认云存储权限
3. 使用云存储的文件ID
